# SmartRoute DSS - FlashLogistics

## Descripción
Sistema de soporte a la decisión para mejorar la planificación de rutas, el rastreo de entregas y el análisis operativo de FlashLogistics.

## Objetivo SMART
Desarrollar en 3 meses un DSS logístico que reduzca en 20% las entregas tardías y en 10% los costos de combustible mediante rutas optimizadas, rastreo en tiempo real e indicadores operativos.

## Canvas MVP
| Elemento | Contenido |
|---|---|
| Propuesta del MVP | Sistema mínimo para planificar rutas, rastrear entregas y visualizar indicadores. |
| Personas atendidas | Gerente de operaciones, despachador, conductor y cliente. |
| Viajes atendidos | Planificación diaria, seguimiento de entregas, consulta de pedidos y análisis de desempeño. |
| Funcionalidades | Gestión de rutas, rastreo, consulta de estado, dashboard y reportes básicos. |
| Resultado esperado | Reducir retrasos, combustible y llamadas de clientes. |
| Métricas | Entregas tardías, combustible, llamadas, tiempo de planificación y desempeño por conductor. |
| Cronograma | 6 sprints de 2 semanas. |
