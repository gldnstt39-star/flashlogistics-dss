# Actividad 5 - Arquitectura de Persistencia

Esta carpeta contiene los modelos de persistencia de datos del proyecto SmartRoute DSS - FlashLogistics.

## Archivos incluidos

- Diagrama de clases UML de persistencia.
- Modelo relacional de base de datos.
- Script SQL inicial para la creación de tablas.
- Diccionario de datos básico.

## Objetivo

Diseñar la estructura de datos que permitirá registrar pedidos, conductores, vehículos, rutas, entregas, alertas y reportes operativos, asegurando integridad referencial y soporte a la toma de decisiones.
